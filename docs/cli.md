# CLI

## Core commands

- `dsp init`
- `dsp index [path]`
- `dsp bootstrap [path]`
- `dsp update --from-git-diff`
- `dsp changed`
- `dsp search "<query>"`
- `dsp impact <uid-or-path>`
- `dsp validate`
- `dsp export --format json|dsp`
- `dsp import <graph.json>`
- `dsp mcp`

## CI commands

- `dsp precommit-check`
- `dsp ci check`
- `dsp ci impact`
- `dsp ci context-summary`

Most commands support `--json` for machine output.
